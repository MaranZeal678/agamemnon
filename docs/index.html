01 · The missing back end

Agents run code no compiler has checked.

An LLM is a nondeterministic front end. It emits intent: SQL, file edits, API calls, plans. Today that output goes straight to the world, with the agent holding real credentials.

02 · The pipeline

Four passes between intent and effect.

Compiler stageAgamemnonWhat happens
1static analysisPreviewThe connector measures what the action would really do, not what the agent claims, and labels the preview honestly: exactestimatedrendered
2linking & signingBindApproval is bound to the hash of that measured effect plus a precondition token (row-set hash, blob SHA, saved-plan hash, charge state). If the target drifts, nothing runs.
3effect type systemAdmit by reversibilityEvery effect is typed before it runs: undocompensateholdirreversible Irreversible effects need two people or become a cancellable hold.
4runtime checksVerifyThe agent's claims (“only touched staging”, “tests pass”, “refunded $50”) are checked against systems of record it cannot write to. A contradiction tightens what it may do next.
PostgresfilesGitHubTerraformStripeemailDatadog / PagerDuty

One back end, seven connector targets; each implements preview → bind → execute → verify → compensate. “Compiler” is an analogy: Agamemnon is a reference monitor that mediates every action at run time.

04 · The effect type system

Typed by reversibility, before it runs.

undo
Restore from a before-image. A Postgres delete, a file edit. Selective revert keeps rows a human edited afterwards.
compensate
Reverse with a compensating action. A customer credit, a muted monitor, a branch-protection change.
hold
Irreversible once it leaves, so it waits in a cancellable window. An email in the outbox, a held refund, a delayed delete.
irreversible
Needs two people. Terraform destroying a database and its backups is typed here, and blocked when it matches a rule.

06 · The runtime

A sandboxed runtime for LLM-written programs.

Agent-generated scripts, third-party plugins and agent swarms run with no ambient authority. Their only way to touch the world is a broker proposal.

QuickJS-Wasm enclaves light tier

  • Isolation by absence. Each sandbox is its own Wasm module; the guest gets three host functions and nothing else: no fs, network, timers or modules.
  • Capabilities, not trust. Nothing implies anything else.
  • A violation kills. An ungranted syscall kills the sandbox, ends its broker task and is audited.
  • Writes are proposals on a task scoped to the sandbox's tenant.
READ_ONLYMUTATE_STATEEXTERNAL_HTTPAGENT_IPC

Firecracker microVMs heavy tier, KVM

  • A fresh microVM per run, running Python with hardware isolation.
  • No network device, read-only root, vsock only to the host.
  • Hard deadlines. while True: pass is destroyed at its deadline; memory past the cap kills the guest, not the host.
  • Same policy. Granted syscalls reach the broker; an ungranted one kills the sandbox.

Limits: no jailer yet; ~4 s boot under nested virtualization. The QuickJS tier checks deadlines between bytecodes, so it is not hard preemption.

pre-tool hook = early warning (advisory) broker = the real boundary (holds the keys)

09 · Lineage & licence

What we claim, and what we don't.

Built on prior work

Building on sagas, WYSIWYS, and selective-repair systems (Retro / Warp / Aire), and complementary to data-flow defences (CaMeL, FIDES, Progent), we claim only the combination plus effect semantics: across heterogeneous systems, typing each agent effect by reversibility before execution, binding human approval to that previewed effect, and verifying the realised effect against systems of record afterwards, with oversight-reducing actions as a distinct enforcement class.

We do not claim to be the first credential broker, rollback, undo, provenance, audit log, approval flow or agent guardrail, nor to undo SaaS side effects that have already fired.

Current limits: single-node broker; GitHub, Stripe and Datadog tested against mock APIs; hooks are advisory. All honest limits · threat model

Open core, Apache-2.0

Anything that makes an agent safe is open. You can run the whole preview → bind → admit by reversibility → verify loop without paying for anything.

  • Open: kernel, broker and every connector, MCP server, hooks, CLI, mini-sandboxes, the Larkspur demo, the bench, deploy files and docs.
  • Proprietary: the full operator console and compliance annotations (Agamemnon Enterprise, loaded as a broker extension), and the desktop apps, which carry their own licences.
  • Approvals work without the console, from the approval page or the CLI.
