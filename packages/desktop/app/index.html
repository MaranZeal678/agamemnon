The scenario

An AI agent was told to clean up a bank's database.
It tried to delete everything.

A software engineer at NorthBridge Bank hands an AI agent a routine job: remove flagged transactions from the production Postgres database. A subtle bug makes the agent's query match every record. Without a guardrail, 240,000 live transactions vanish and no monitor notices. Agamemnon sits on the write path and stops it.

01

Record atomically

Every write and its audit entry are saved together. No action without a trail.

02

Measure blast radius

Agamemnon counts the real rows with its own access — not the number the agent claims.

03

Decide by policy

Deterministic rules allow, hold for approval, or block. The AI can only make it stricter.

04

Keep it reversible

Rows are snapshotted before deletion. Undo restores the exact rows in seconds.
